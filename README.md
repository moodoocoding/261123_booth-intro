# AI 체험 부스 소개 슬라이드

2026 충북 AI 페스티벌 체험 부스에서 화면에 띄워 두는 소개 페이지입니다. 학생들이 만든 앱과 게임 24개를 한 장씩 보여 주며, 10초마다 자동으로 다음 장으로 넘어가고 끝나면 처음으로 돌아갑니다.

- `index.html`: 슬라이드 (1920×1080 고정 화면을 통째로 화면 크기에 맞춤)
- `shots/`: 게임 화면 사진 (각 게임 첫 화면. 2026-11-26에 더한 11장은 부스 모음 사이트의 썸네일을 가져온 것)

## 쓰는 법

- ← → 키: 앞뒤로 넘기기 / 스페이스: 멈춤·다시 시작 / 화면 누르기: 다음 장
- **QR 코드**: 오른쪽 위 카드에 지금 소개하는 게임으로 바로 가는 QR 코드가 나옵니다. 슬라이드가 바뀌면 QR 코드도 바뀝니다. 주소는 부스 모음 사이트(https://ai-festival-booth.vercel.app/)의 게임별 주소이며 `index.html`의 `HUB`와 `GAMES`의 `url`에서 고칩니다. 첫 장은 모음 사이트 첫 화면으로 갑니다.
- 넘어가는 시간: `index.html` 위쪽의 `--auto-ms:10000ms` (10초)
- 게임 추가·문구 수정: `index.html`의 `GAMES` 목록
